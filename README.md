# The Damage Report

Website for *The Damage Report*, a podcast about why we're like this.

A single static page (`index.html`, inline CSS and JS) served by GitHub Pages at https://tdr.backwoodstechsolutions.com.

To add podcast platform links, replace the `<span class="platform" aria-disabled="true">` placeholders in the Listen section with `<a class="platform" href="...">` links.
